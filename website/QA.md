# Type product page QA

Validated November 12, 2026 on branch `feat/type-product-site`. All browser QA used Astro production builds served at localhost:4400. There were four comprehensive screenshot passes, three independent screenshot critics, plus final targeted desktop/mobile sequence and interaction captures. The independent scores progressed from 7.69 to 7.90 to 8.17. Scores are estimates, not awards.

## Final results

- `npm run check`: 0 errors, 0 warnings, 0 hints.
- `npm run build`: passes.
- awwwards `audit.mjs`: **0 FAIL, 0 WARN**; page weight approximately 532 KB, JavaScript approximately 50 KB gzipped.
- Comprehensive pass-four home: throttled mobile LCP **1648 ms**, CLS **0.007**, scroll FPS **60**. Desktop FPS **60**. Measurements are headless with a software GPU; not physical-device measurements.
- 404: mobile LCP 680 ms, CLS 0; real HTTP 404 verified.
- Home and 404: no browser runtime errors, failed requests, horizontal overflow, small targets, axe violations, missing focus styles, invisible focus stops, or unchanged hover targets.
- Keyboard: skip link first, controls and disclosures in reading order, no trap.
- Reduced motion: zero hidden text, still rendering, no smooth scrolling or pinned scene.
- Functional verification: **26/26 checks pass**, including focus on/off, all theme changes, loaded image outcomes, all disclosures, actual GitHub destinations, widths 390/768/1024/1440/1920, reduced motion, no-JavaScript access and HTTP 404.
- The app screenshot and deliberately dimmed native focus text were manually inspected. Automated contrast review flags for image-backed/moving regions are not actual reported axe violations.

## Data and deployment safeguards

All 53 preexisting repository files were hashed before website work and remained byte-identical after implementation. The user's uncommitted native app improvements were preserved and excluded from the website commit. Actual product media contains only original sample writing. See `public/media/PROVENANCE.md` for capture isolation and the corrected initial app-resolution issue.

Vercel dry run: only website sources/assets/configuration. Native app source, all `.env*`, `.vercel`, node_modules, build output, scripts, and all `.shots*` directories are excluded. Dedicated project `type-product-page`; Git deployments disabled. CLI deployment explicitly targets Preview; no production deployment, GitHub push, merge, or domain promotion.
